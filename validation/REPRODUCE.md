# Reproduce the cross-release comparison

Run from the repository root. Use three *separate* directories: legacy interpreter,
modern interpreter, benchmark output. No pickle/joblib files are used.

1. Install the production requirements into an isolated Python 3.12 environment.
2. Prepare data with the production loader (full checkout required):
   `python tests/prepare_benchmark.py --output /path/to/benchmark/input`.
3. For independent regeneration of the reference, create an isolated Python
   3.5.5 environment and install the exact packages listed in `legacy-environment.md`. This reconstruction
   uses scikit-learn **0.18 exactly**, as reported for the paper, with compatible
   period libraries. The paper did not fully specify this interpreter/dependency
   combination, so it is not asserted to be the authors' exact original environment.
   The recorded run used conda-forge osx-64 Python 3.5.5 and official PyPI wheels
   under Rosetta. Keep this obsolete environment offline except during installation.
4. Run `OLD_PYTHON tests/benchmark_forest.py --baseline --inputs /path/to/benchmark/input
   --output /path/to/benchmark/baseline`.
5. Run `NEW_PYTHON tests/benchmark_forest.py --inputs /path/to/benchmark/input
   --reference /path/to/benchmark/baseline --output /path/to/benchmark/modern`.
   Alternatively use the committed `validation/baseline` directory as the reference.

The benchmark uses all compounds in each target, five frozen stratified folds
from 0.18 (split seed 1729), 1,000 trees, model seeds 0/1/2 without docking score,
and seed 0 including docking score. Every compound has an out-of-fold prediction.
It exits nonzero if any preregistered comparison threshold fails. `--targets`
can limit a rerun to one or more of CAG/FXI/HIV.

Thresholds were chosen before reading modern results: probability MAE <=0.02,
maximum probability difference <=0.10, Spearman rank correlation >=0.98,
absolute pooled out-of-fold AUC difference <=0.02, and active count differences
in the top 1% and 10% <=2. These are engineering acceptance criteria rather than
an equivalence test derived from the publication. Report the actual differences,
not just a pass/fail. Feature importance L1 difference is diagnostic only.

The comparison excludes the original first-compound-dropping bug in *both*
environments to isolate library behavior. All-data predictions use the corrected
loader. CLI folds are generated by the installed sklearn version; matching seed
alone does not guarantee the same folds across versions.

NPZ references contain numeric arrays only (`allow_pickle=False`), with folds,
labels, probabilities, and fold-mean feature importance. Their compound row order
is determined by the source CSV hashes in `input-manifest.json`.

For report-only comparisons, run `tests/benchmark_reports.py` in each environment
with `--inputs`, `--reference`, `--scoring-path`, and `--output`. Use the original
`scoring.py` and `calc_ef.py` extracted together from commit
`ada055bc41758dd05e98951f9d84f221741e1f17` for the legacy run, and the migrated
`scoring.py` for the modern run. This reuses fixed predictions rather than refitting.
The final forest run used `--n-jobs 4`; the legacy reference used its default of 1.
